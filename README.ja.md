# ⚙️ Sephiria Expanded MOD
[한국어](README.md) | [English](README.en.md) | **日本語** | [简体中文](README.zh-CN.md)

Sephiriaのプレイを補助するHorayModAPI MODです。

[Steamワークショップ](https://steamcommunity.com/sharedfiles/filedetails/?id=3832216646) | [更新履歴](https://github.com/psyche-kr/Sephiria-Expanded-MOD/releases) | [ロードマップ](https://github.com/psyche-kr/Sephiria-Expanded-MOD/blob/main/ROADMAP.md) | [要望・不具合報告](https://github.com/psyche-kr/Sephiria-Expanded-MOD/issues)

## 💡 導入方法
1. [Steamワークショップ](https://steamcommunity.com/sharedfiles/filedetails/?id=3832216646)でSephiria Expandedをサブスクライブします。
2. ゲームを起動するとMODが適用されます。新しいバージョンはSteamが自動でダウンロードします。
3. すべての機能はESCメニューの`Sephiria Expanded`ボタンからオン・オフできます。設定画面は韓国語、英語、中国語（簡体字）、日本語に対応しています。

## 🧩 ソースコード
MODのソースは[`src/`](src)にあります。ゲームが提供する内部API（`HorayModBase`）を継承したエントリーポイントから、[Harmony](https://github.com/pardeike/Harmony)でゲームのメソッドをパッチする方式で動作します。

| 場所 | 役割 |
| --- | --- |
| `src/SephiriaExpanded/Main.cs` | MODのエントリーポイント。設定の読み込み、Harmonyパッチの適用、ランタイムオブジェクトの生成と解放 |
| `src/SephiriaExpanded/ModSettings.cs` | オプション値の保存と読み込み |
| `src/SephiriaExpanded/ExpandedSettingsPanel.cs` | ゲームの設定画面に付くMODオプションUI |
| `src/SephiriaExpanded/Features/` | 機能ごとのファイル（ダメージメーター、ボスチャレンジ、隠し部屋の追跡、財布の共有など） |

**ビルド**: Visual Studio 2022で`src/SephiriaExpanded.sln`を開きます。ゲームのDLL（`Assembly-CSharp`、`Mirror`、`UnityEngine.*`など）はリポジトリに含まれていないため、`SephiriaExpanded.csproj`の`HintPath`を自分のゲームのインストール先（`Sephiria_Data/Managed`）に変更してください。

## ✨ MODの機能
**便利機能**
- チャット便利機能: 時刻、チャット欄のスクロール、/clear（チャット欄を消去）、アイテム等級の表示などの便利機能を追加します。
- ショップでお気に入り表示: お気に入りにしたアイテムの表示をショップでも見えるようにします。
- エンチャント回数表示: アイテムのエンチャント数値を表示します。
- プリセットスロット拡張: プリセットスロットを最大100個に増やします。
- オートラン: 走れる状況であれば常に走り状態を維持します。
 - 走りの慣性除去: 走るときにゆっくり加速したり、止まるときに滑ったりせず、入力した方向にすぐ動き、すぐ止まります。
- 隠し部屋の追跡: 隠し部屋の位置を画面に表示します。
- 残り報酬回数の表示: 選択肢を選ぶときに、残りの報酬獲得機会がいくつあるかを表示します。
- ミニマップ全表示: ミニマップを明るく表示します。
 - ミニマップ移動を許可: ミニマップをクリックして遠くの場所にも移動できます。
- 戦闘中にバッグを開く: 戦闘中でもバッグとステータス画面を開けるようにします。
- ボスHPの数値表示: ボスのHPバーの上に正確なHPを数値で表示します。（パーセントは小数点以下1桁まで表示します。）
- ボスのターゲット表示: ボスの攻撃対象になったプレイヤーを白い枠で表示します。
- 特殊攻撃・魔導書・発動型の自動使用: キーを押し続けている間、使用し続けます。
- MODアイテムのツールチップ: アイテム説明のUIに、そのアイテムがどのMODで追加されたかを表示します。
- FPS表示: 画面左上に現在のフレームレートを表示します。
- ダメージメーター: 個人とパーティのダメージ量とDPSを測定して画面に表示します。（個人DPS、個人の累計ダメージ、パーティDPS、パーティの累計ダメージ）Altを押しながらウィンドウを移動できます。
 - メーターのショートカットキー: メーターのウィンドウを表示・非表示にするキーを設定します。
- キルログ表示: フレンドリーファイア許可の下位項目にキルログのオプションが追加されます。プレイヤーを倒した相手（モンスター、プレイヤー）の名前をチャット欄に表示します。MODのないゲストにはログが表示されません。
- ニックネームの色: 自分のニックネームの色を12色の中から変更します。（MODのないゲストにも色が見えます。）グラデーション色1、2を設定すると、ニックネームの色 → グラデーション色1 → グラデーション色2 の順につながるグラデーションが適用されます。
- マルチ退出時に始まりの村へ移動: ゲストとしてマルチプレイのセッションから抜けると、タイトル画面ではなく自分の始まりの村へすぐに移動します。
- マウスカーソルの視認性向上: マウスカーソルの縁取りが太くなり、縁取りの色を変更できます。

**成長 / アイテム**
- レベルごとにバッグ支給: 設定したレベル数上がるたびにバッグのスロットを支給します。
- プレイヤーレベル上限拡張: 基本のレベル上限（30）が60に上がります。ホストにのみ適用され、ゲストも使うにはMODが必要です。
- ゴールド・経験値の即時取得: ゴールドと経験値を獲得するときに出るオブジェクトをなくし、すぐに獲得します。
- 初期アイテムを売却可能: ゲーム開始時に支給されるコスチュームの基本アイテムもショップで売れるようにします。
- 最初のアーティファクト伝説保証: ゲーム中に初めてアイテムを獲得するまで、アーティファクトの選択肢が常に伝説等級以上になるよう保証します。リロールしても維持され、アイテムを1つ獲得するとそれ以降は通常に戻ります。
- 最初の石版伝説保証: ゲーム中に初めて石版を獲得するまで、石版の選択肢が常に伝説等級以上になるよう保証します。リロールしても維持され、石版を1つ獲得するとそれ以降は通常に戻ります。（伝説の候補が足りない場合、残りの枠はバニラのまま出ます。）
- エンチャント祭壇3回固定: すべてのエンチャント祭壇が3回エンチャントできる祭壇に固定されます。
- 最初の部屋に金床保証: 1、2層の最初の部屋に金床を必ず配置し、強化できるすべての武器のリストを表示します。
- かかしのHP増加: 訓練場のかかしのHPが100倍になります。

**コスチューム / 図鑑エフェクト**
- 根退き武器の枠エフェクト: ハードモード15/30/50/60をクリアした武器をジャーナルに表示します。（Aタイプ、Bタイプ、Bタイプ(S)から選択）
- 根退き武器のきらめきエフェクト: ハードモード60をクリアした武器を持っていると、武器にきらめく光のエフェクトを表示します。MODを使っている仲間の武器にも表示されます。
- 根退きコスチュームのアニメーション: ハードモード60をクリアしたコスチュームのバナーを飾ります。

**願いの泉**
- 願いの泉で全アイテム解禁: 願いの泉に結束のアーティファクト、石版、怪しい商人が販売するアーティファクトも預けられます。
- 願いの泉の拡張: 願いの泉の最大容量を増やします。
- 願いの泉のアーティファクトを他人が拾える: 願いの泉から持ってきたアーティファクトを捨てたとき、他のプレイヤーも拾えるようにします。

**マップ / イベント**
- マップ拡張: 拡張できる階層なら、4～6部屋の間でランダムに拡張します。（ゲストも使うにはMODが必要です。）
- ランダムイベント出現の重み: 献血、墓石、怪しい商人、ポケットディメンションの商店などのランダムイベントが発生する確率の倍率を調整します。（最大にしても必ず出現するわけではありません。）
- 神秘の壺の確定出現: 神秘の壺が出現しうる状況では、ランダムではなく100%出現します。
- 商人のバッグ確定販売: 小商人がバッグを100%販売します。
- クリフォトの演出スキップ: 5層のクリフォトと6層のクリフォト第1フェーズの演出をスキップします。

**マルチプレイ**
- 最大人数拡張: マルチプレイの最大人数を16人まで増やします。
- 幸運のメダル共有: 幸運のメダルの効果をパーティメンバーと共有します。
- ポーション獲得の共有: ポーションを獲得すると、パーティメンバー全員に支給します。
- フレンドリーファイア許可: 味方にダメージを与え、味方からダメージを受けることがあります。
- ピン音の調整: ピン音を消したり、繰り返し聞こえないようにします。（3秒に1回、5秒に1回、ミュート）
- ピン連打防止: 次のマップへ移動するポータルを調べたり移動しようとしたときに出るピンと通知を、すべてのプレイヤーがステージごとに1回だけ出せるよう制限します。
- 仲間の通貨表示: マルチプレイで、仲間のHPバーの下に、仲間が持っているサイコロ、サファイア、ゴールドの量を小さく表示します。
- 仲間と通貨を共有: すべての仲間のゴールドまたはサイコロをまとめ、ひとつの共用財布として使い、管理します。（ゴールド共有、サイコロ共有を選択）（MODのないゲストも利用できます。）

**パターン強化**
- パターン強化: すべてのモンスターの全体的な倍率が上がり、ボスモンスターのパターンが強化・追加され、今までよりさらに難しくなります。（MODのないゲストも遊べます。）（MODのないゲストのチャット欄にはボスのセリフが表示されません。）
 - 全体難易度: すべての階層とボスに一括で適用される難易度段階です。全体難易度をオンにすると、ノーマルは+300%、ハードは+500%のサファイアを追加で獲得します。
 - ボスのブレイクゲージを使用: ボスのHPバーの下にブレイクゲージが表示され、ゲージをすべて削るとボスがしばらく倒れます。
 - 推奨倍率を適用: パターン強化の難易度に合わせてモンスターの倍率も上げます。（ノーマル / ハード）通常モンスター・ミニボスのHP x2 / x4、通常モンスターの生成数 x2 / x2、通常モンスター・ミニボスの攻撃速度 x1.2 / x1.2、ボスのHP x2 / x4、ボスの攻撃力 +15% / +25%。倍率タブで直接調整した値とは掛け合わせず、高い方を適用します。

**モンスター倍率の設定**
- モンスターの生成、HP、ダメージ、パターン速度の倍率を調整します。
- ミニボスにも生成倍率を適用: 生成倍率の分だけミニボスも増やすかを選びます。
- 経験値・ゴールド獲得量を倍率分減少: オンにすると、生成倍率で増えたモンスターがゴールドと経験値を追加で与えないように補正します。
- 血の祭典の緩和: オンにすると、HP倍率で増えたモンスターのHPによって、血の祭典の効果の回復量まで増えないように補正します。

**その他**
- 言語: MOD設定画面の表示言語を変更します。（韓国語 / 英語 / 中国語 / 日本語）最初はPCの言語に合わせて決まります。MODが表示する通知やボスのセリフもこの言語に従います。
- 更新履歴: チェックすると、MODの更新履歴（リリース）ページをWebブラウザで開きます。
- すべての設定をリセット: MODのすべての設定を初期値に戻します。

## 💡 パターン強化で変わること（ノーマル/ハード）
**1層 モグディ**
連携攻撃: 通常攻撃、二連撃、ダイナマイト、手の叩きつけの後に次の攻撃が続きます（最大2回）。続く確率は50/100%、再使用待機時間は5/2.5秒です。
ダイナマイトを投げるとき、左右に5個ずつ多く投げます。
手の叩きつけが12方向の放射状の衝撃波に変わります。
ジャンプの着地時と空中から降りてくるとき、ダイナマイトを四方にばらまきます（6/12個）。
空中にいる間は1秒ごとに落石が2個落ち、ドリルダイナマイトの発射間隔が半分になります。
2秒ごとにプレイヤーの近くに落石が落ちます。20秒ごとにステージ全体に落石が雨のように降り注ぎます。
ドラムステージの攻撃のとき、落石が2/3個ずつ多く落ちます。
ハード: 14秒ごとに2列で掃く落石が出ます。第2フェーズでは端まで行って戻ってきます。
第2フェーズが始まるとHPが全回復します。
セリフ: 遭遇、ダイナマイトパターン、各フェーズのHP50%未満、第2フェーズの着地、死亡。

**1層 オードナー**
爆弾パンチを使った後、もう一度使います。
ミサイルパターン中に0.5/0.25秒ごとにダイナマイトを投げます。ミサイルの後には7重の輪の形の爆発が広がります。
爆弾散布のとき、爆弾を1/2個多く投げます。リモートダイナマイトは上下2列で順番に爆発するように変わります。
オーバーヒート（HP20%以下）: パターン間の待機が短くなり、5秒ごとに爆弾を投げ、HPバーの色が変わります。
ハード: 突進中に左右へダイナマイトを投げます。オーバーヒート状態では爆弾散布とリモートダイナマイトをもう一度使います。
セリフ: 遭遇、HP50%、オーバーヒート、死亡。

**1層 ハズ**
バニラのハードパターンを強制的にオンにせず、ブレイクゲージもありません。
列攻撃の弾数: ノーマルはそのまま、ハードは1発追加されます。
ポイント攻撃のとき、マップ内のランダムな位置から触手が追加で生えます。
レーザーが2本に増えます。ハードでは、レーザーが1周した後、反対方向にもう一度回ります。
ハード: 1.5秒ごとにマップの端に沿って触手が生えます。列攻撃の50%が縦列攻撃（警告0.75秒、遅い弾）に変わります。
セリフ: 遭遇、死亡。

**2層 ラタカ**
弾幕パターンを円形、扇形、回転、交差のいずれかに作り直しました。弾幕を使っている間に狙い弾を12発撃ち、ハードではこの狙い弾がプレイヤーを追いかけます。
落石がより密な直線に変わり、弾幕が終わった後に落ちます。
バニラの召喚パターンをなくし、代わりに定期的に手下を召喚します（16/10秒ごと、最大8体）。
セリフ: 遭遇、召喚、HP50%、死亡。

**2層 レリッド**
合計4回突進します。ハードでは2回目と4回目の突進ごとに手裏剣を8方向に追加で撃ちます。
通常攻撃の2撃目が30°間隔の12方向の弾に変わり、警告もそれに合わせて表示されます。ハードでは45°間隔の手裏剣も撃ちます。
遅い手裏剣の数: 1回目7/8、2回目5/6、広がる角度は80°です。
狙いの短剣パターンで分身が1/2体増えます。順次短剣の2体目の分身は遅い手裏剣を5発投げます。
セリフ: 遭遇、突進、分身、HP50%、死亡。

**3層 エルマ（ゴーレム）**
ブレイクゲージがありません。
ゴーレムの手にはダメージが入りません。
ゴーレムのフェーズが1/2個増えます。第4フェーズでは1秒ごとにミサイルパターン（直線、収束、格子のいずれか）を使います。ハードでは第5フェーズが追加され、移動速度20%、レーザー速度30%で、補助射撃とレーザーのみを使います。
手の叩きつけは5回、衝撃波は5回に固定され、ハードでは叩きつけるたびに衝撃波が出ます。
拡散弾は5セットで、18/20発、0.66/0.56秒間隔です。
セリフ: ゴーレムの遭遇、第4・5フェーズ突入、死亡。

**3層 ペンタクシス**
ジグザグ弾のパターンのときに秩序の爆発を一緒に使います。
回転突進のときにチャクラムを一緒に使います。チャクラムと火球は単独のパターンとしては出てきません。
ジャンプ攻撃やレーザーのときに火球が1個出て、HP50%未満なら2個、ハードでHP10%未満なら3個出ます。
ハード:
ジグザグ弾の発射間隔が1.2秒から1.0秒に、発射回数が7回から8回に変わります。
秩序の爆発の警告が2秒から1.6秒に変わります。
ジャンプ攻撃が5回に固定されます。
火球が消えた場所から破片が6発出ます。
HP10%未満になると殲滅状態になり、HPバーの色が変わります。
セリフ: 遭遇、回転突進、ジャンプ、HP50/10%、死亡。

**4層 アスカード**
パターンの順番はバニラのままです。
触手パターン:
埋め尽くし: 列の間の待機が1秒から0.88/0.75秒に変わります。
波: 掃く間の待機が0.75秒から0.66/0.5秒に変わります。
ポイントとライン: 触手の列が1列ずつ追加され、ラインはプレイヤー方向の±45°に追加されます。
叩きつけ: 警告が2秒から1.88秒に変わります。着地の弾が2/4発増え、ハードでは1.5秒後にもう一度叩きつけます。
レーザー: 扇形を最後まで撃った後、警告なしで反対方向にもう一度撃ちます。ハードではレーザーの警告が2秒から1.75秒に変わります。
その他: 血の唾は両側から一緒に出ます。暗黒パターン内のレーザー間隔は1.25～0.45秒から1.20～0.40秒に変わります。
セリフ: 登場、叩きつけ、レーザー、HP75/50/25%、死亡。

**5層 コベス**
二連斬り: ノーマルは1→2→1撃、ハードは1→2→1→2撃とつなげて使います。
帯状の爆発: 終わると、使わなかった方向（横/縦）にもう一度爆発します。
飛行トルネード: 警告を1つずつ表示した後、警告の順番に爆発します。ノーマルは警告1.33秒間隔、1.66秒待機、1.33秒間隔で爆発し、ハードは1秒、1.5秒、1秒です。
外周の嵐の弾: 速度が6%/12%速くなります。
円形弾: 4番目、8番目、12番目…のパターンの順番にのみ出ます。
ハード: 戦闘開始から12秒後から、12秒ごとに落下弾が5個落ちます。
セリフ: 遭遇、飛行トルネード、HP90/50/25%、死亡。

**5層 クラーズ**
ハード:
頭の叩きつけが3連撃に増えます。
叩きつけの弾がバニラの扇形の外まで360度に広がります（バニラの間隔で埋めるより4発少なく）。
突進の速度が15%速くなります。
